# Tratar Direito

Portal gratuito de orientação a famílias de pessoas com doenças raras e ultrarraras: o caminho até o tratamento, os documentos, o relatório médico, o que os tribunais exigem e a rede de apoio.

Site estático de um único arquivo (`index.html`). Desenvolvido com apoio de Pamplona & Paradela Advocacia.

Conteúdo informativo, atualizado em novembro de 2026. Não substitui a análise individual de cada caso.
